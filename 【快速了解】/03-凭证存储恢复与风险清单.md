## 3. 凭证验证分类器（auth/pzrz.js）

七态结果：`{ ok, status, reason, message, canMarkInvalid, canClearLocal, canRetry, detail }`。
判定顺序（`classifyPayload` 138-167）：

1. 消息含"账号不存在/被禁用…" → **invalid**（可标云端失效）
2. HTTP 401 或 `needLogin===true` → **expired**
3. HTTP 403 或权限词 → **permission_denied**（不判死）
4. 消息含"登录过期/请重新登录/token失效…" → **expired**
5. 5xx / 其他 4xx → **temporary**（可重试）
6. 业务 code≠0 → SCM 记 temporary；PMS 记 valid-skipped

系统入口 `verify('scm'|'pms'|'bi', acc)`（177-183）：
- SCM：`ChaxunConfig.api.url`（gongn/chaxun/config.js:4）真实试查 pageSize=1；
- PMS：无 token → 直接 valid（跳过验证）；无 pmsUrl → valid；
- BI：本地 JWT exp 过期即 expired；再走代理 `/api/validate-token`；验证前**临时覆写 `bi_login`**，finally 还原（并发覆盖风险）。

## 4. 凭证生命周期操作速查

| 场景 | 入口 | 行为 |
|---|---|---|
| 手动登录成功 | `showLoginSuccess` → `syncSharedCredentialAfterLogin`（app.js:471-487） | 本地落盘；云端已有共享物则"缺什么补什么" |
| 手动共享/私有 | "凭证管理" → `shareCurrentCredential/unshareCurrentCredential`（app.js:742-841） | SCM 两模式（secret/credentials）独立开关；PMS/BI 仅完整凭证 |
| 启动恢复失败 | `handleVerificationFailure`（auth/app.js:251-262） | 按七态清本地/标云端失效；SCM 清本地保留 account_secret |
| 点失效账号 | `validateAndSwitch`（app.js:1050-1085） | 标失效 + 打开登录表单 |
| 取消共享 | `unshareLogin`（fir.js:362-401） | 单模式清字段；全空删节点+清所有设备索引 |

## 5. 已知问题与风险清单

| # | 等级 | 问题 | 位置 | 建议 |
|---|---|---|---|---|
| 1 | 高 | account_secret 全链路明文（localStorage + RTDB），Firebase apiKey 硬编码前端，RTDB 规则一旦放读即全量泄露 | app.js:2044、fir.js:4-13,257-265 | 云函数侧加密存 secret；收紧 RTDB 规则 |
| 2 | 中 | SCM/PMS 二维码超时定时器在 setTimeout 里 throw，无人接住，死代码；靠服务端 TIMEOUT 兜底 | scm.js:223-228、pms.js:115-120 | 回调内走 reject |
| 3 | 中 | 轮询失败后登录按钮置"重试"但未绑定 click（只有点二维码图可刷新） | app.js:1671-1678 | 绑定刷新处理 |
| 4 | 低 | getDeviceLogins N+1 请求，恢复/自动填充慢 | fir.js:439-496 | 索引内带全量或批量读 |
| 5 | 低 | 自动填充只试最近一条设备账号，其无 secret 时不回退更早账号 | app.js:1443-1452 | 改为遍历前 N 条 |
| 6 | 低 | BI 凭证验证临时写 bi_login 再还原，并发恢复时可能互相覆盖 | pzrz.js:292,316-318 | 内存态传递代替 localStorage 中转 |
| 7 | 低 | PMS 无 token 凭证直接判有效，空壳凭证可进账户列表 | pzrz.js:229-233 | 无 token 时降级为 temporary |
| 8 | 低 | 设备指纹折叠后仅 24bit，约 4300 台设备 50% 碰撞（生日界）；碰撞会串设备索引 | zhiwen.js:128-137 | 扩到 4 字节以上 |
| 9 | 低 | 共享池逐个真实验证（tryAccounts），账号多时启动恢复线性变慢（有 10s 竞速兜底） | auth/app.js:236-249 | 并行验证或缓存短期结果 |
