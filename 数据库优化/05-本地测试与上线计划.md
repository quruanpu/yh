# 05 · 本地测试与上线计划（先本地测透，GitHub 后上线）

> 用户定调：GitHub push 上线延后；先完完全全本地测试，通过后再部署。
> 注意：D1/Worker 部署在 CF 云端是本地测试的前提（D1 无本地版本可用），"本地"指前端跑在 localhost，连真实 Worker + 真实 D1。

## 阶段 0：授权与基础设施（一次性）

1. `npm i -g wrangler`（npmmirror 源）
2. `wrangler login` → 调起浏览器 → 用户登录 Cloudflare 点 Allow（授权令牌落本机）
3. `wrangler d1 create yh-data` → database_id 写入 `sjk/worker/wrangler.toml`
4. `wrangler d1 execute yh-data --remote --file schema.sql`（建 docs 表 + 索引）
5. `wrangler secret put YH_TOKEN`（生成 40 位随机令牌，同步写入 `sjk/app.js config.token`）
6. `wrangler deploy` → 输出 `*.workers.dev` 地址（记入本文档与 sjk config）

### wrangler.toml 设计
```toml
name = "yh-data-gateway"
main = "worker.js"
compatibility_date = "2026-01-01"
[[d1_databases]]
binding = "DB"
database_name = "yh-data"
database_id = "<创建后回填>"
[vars]
ORIGIN_ALLOWLIST = "ly.cqytyy.top,cqytyy.top,localhost,127.0.0.1"
TOKEN_REQUIRED = "true"
```
说明：Origin 白名单走 vars（改域名不用重发 secret）；cqytyy 后缀匹配在 Worker 内实现（allowlist 存根域，`endsWith('.cqytyy.top') || host === 'cqytyy.top'`）。

### schema.sql 设计
```sql
CREATE TABLE IF NOT EXISTS docs (
  collection TEXT NOT NULL,
  id TEXT NOT NULL,
  data TEXT NOT NULL,
  updated_at INTEGER NOT NULL,
  PRIMARY KEY (collection, id)
);
CREATE INDEX IF NOT EXISTS idx_docs_collection ON docs(collection);
```
（json_extract 查询带 collection 主键前缀过滤，数据量小无需额外索引。）

## 阶段 2：前端驱动切换（sjk/app.js 内部重写）

- 保留：12 个 API 签名、`window.SjkModule`、10s 超时、错误归一、空库容错语义。
- 改变：内部 `this._call(op, params)` → `fetch(gatewayUrl, {POST, x-yh-token 头})`；`init()` 改为健康检查（失败不阻断、标记 degraded）。
- `watchWhere/watchCollection` → **10 秒轮询**：立即首跑一次 → setInterval(10000) → `document.hidden` 暂停 → 恢复可见立即补跑 → unwatch = clearInterval。回调参数 `{ docs, type:'poll' }` 不变。
- `index.html`：删除 CloudBase SDK CDN 行。
- 语法：node --check 全部改动文件。
