# BI汇总查询目标模块需求记录

## 模块职责

- `gj.js`：目标 Excel 模板生成、上传文件解析、目标值格式化、达成率计算。
- `gz.js`：目标周期、实际查询周期、时间进度、默认目标匹配等纯规则。
- `yw.js`：目标上传弹窗、底部目标下拉、数据库读写、目标匹配、目标列与达成列构建。
- `../plcx.js`：BI汇总查询弹窗主体、表格渲染、状态栏、标题日期信息，只调用目标模块提供的能力。

## 数据库存储

目标按供应商隔离，路径：

```text
moban/yeji_mubiao/{providerId}/ultra_v2/ranges/{yyyymmdd_yyyymmdd}
```

Firebase 方法：

```js
getYejiTargets(pid)
saveYejiTargetRange(pid, rangeKey, payload)
deleteYejiTargetRange(pid, rangeKey)
```

## 目标模板

- A1：开始日期。
- B1：用户填写开始日期，支持 `yyyy/mm/dd`、`yyyy-mm-dd` 或 `yyyyMMdd`。
- C1：结束日期。
- D1：用户填写结束日期，支持 `yyyy/mm/dd`、`yyyy-mm-dd` 或 `yyyyMMdd`。
- 第二行开始为模板 ID、项目名称和当前聚合字段目标列。
- A 列模板 ID 不隐藏，用于稳定匹配模板。
- 下载模板基于当前模板列表、合并显示结构和当前用户选择的聚合字段动态生成。
- 如果存在 `模板名称_后缀` 的多条模板，下载模板同时包含合并项 `模板名称` 和子项 `模板名称_后缀`。
- 下载模板会带上当前生效目标周期中已有的目标值；合并项和子项各自读取自身目标记录。
- 下载模板的日期优先使用当前命中的完整目标周期；没有目标时使用当前查询对应的完整周期，避免把目标月底误写成实际查询截止日。
- 上传区域支持点击选择文件，也支持拖拽 `.xlsx` 或 `.xls` 文件到上传区域后再点击上传。
- 上传解析日期只读取模板 B1/D1 的 Excel 显示值或原始序列值，不使用 JS Date 对象，避免时区导致目标日期前移一天。
- 上传保存成功后，立即恢复上传弹窗按钮，再激活刚上传的目标周期并刷新 BI 汇总查询。

## 目标选择

- 不再使用 BI 汇总查询弹窗左侧目标导航、展开、折叠抽屉。
- BI 汇总查询弹窗左下角使用目标下拉。
- 点击目标下拉后，目标列表从按钮处向上弹出。
- 目标选项按 `yyyymmdd_yyyymmdd` 命名，右侧内部保留删除小叉。
- 目标列表宽度随文字自适应，高度不超过屏幕 50%，超出后内部滚动。
- 点击目标项后，将出库日期设置为该目标区间，并刷新 BI 汇总查询。
- 删除目标前需要二次确认。

## 标题与状态栏

- 标题显示为：`BI查询 | 时间进度：xx% | 出库日期：yyyy/mm/dd~yyyy/mm/dd`。
- 时间进度按当前日期在目标周期中的位置计算，目标周期未开始为 0%，目标周期已结束为 100%。
- 当前日期在目标周期内时，实际 BI 查询日期为目标开始日期到当前日期前一天。
- 当前日期早于目标周期或晚于目标周期时，实际 BI 查询日期为完整目标周期。
- 打开 BI 汇总查询时，默认匹配包含当前日期的目标；多个目标命中时选择跨度最小、更新时间最新的目标。
- 没有目标命中时，时间进度优先使用出库日期，其次支付日期；都没有则不展示进度。
- 没有目标且查询日期为本月 1 号到昨天时，时间进度按当前月已过天数 / 当前月总天数计算。
- 没有目标且用户自选查询日期时，时间进度按当前日期在该查询区间中的位置计算；未开始为 0%，已结束为 100%。
- 底部状态栏左侧显示目标下拉，右侧保留目标上传、下载、刷新图标按钮。

## 查询调度

- BI 汇总查询按模板并发请求，默认并发数为 31。
- 每个模板查询完成后立即更新对应行，其它未完成模板继续显示查询中。
- 查询过程中切换目标或刷新时，不继续派发旧批次的新请求；当前批次收尾后自动按新条件重新查询。
- 每个模板使用自身筛选条件查询；BI 汇总请求字段由当前用户字段配置和固定底层字段共同决定。
- BI 汇总实际请求不使用主界面的查询字段；普通模板不传查询字段，合并模板也不传查询字段，只按查询计划补齐必要聚合字段。
- BI 汇总实际请求固定补齐 `含税金额`、`不含税金额`、`不含税p4毛利额`、`不含税仓库人工费`、`不含税配送费`、`不含税平台费`、`不含税边际利润`。
- BI 汇总表头只展示当前用户选择的聚合字段，固定底层字段未被选择时只参与合并计算。

## 目标匹配规则

- 手动查询时，目标按查询日期区间“被目标区间完整包含”来命中。
- 优先使用出库日期；没有出库日期时使用支付日期。
- 如果多个目标区间包含当前查询区间，选择日期跨度最小的目标。
- 如果跨度相同，选择更新时间最新的目标。
- 如果没有目标区间包含当前查询日期，不显示目标列和达成率列。

## 表格展示规则

- 未命中目标时，表格保持普通 BI 汇总查询结构。
- 命中目标后，每个有效目标字段展示为：`字段目标`、`字段`、`字段达成率`。
- 如果某个聚合字段在当前所有项目中的目标都为空或 0，则不显示该字段的目标列和达成率列，只显示实际值列。
- 如果所有聚合字段目标都为空或 0，则回到普通 BI 汇总查询结构。
- 目标模板下载基于当前用户选择的聚合字段生成目标列。
- 合并项目标不由子项自动求和或均值覆盖，目标以用户上传的合并项自身目标值为准。

## 数值规则

- 目标为空显示 `-`。
- 显示值大于等于 10000 时按“万”展示，保留两位小数。
- Excel 下载导出原始数值，达成率导出百分比文本。
- 达成率计算：实际值 / 目标值；目标为空、目标为 0、实际值为空时显示 `-`。
