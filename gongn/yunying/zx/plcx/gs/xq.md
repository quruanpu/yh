# 模板公式（gs/）需求与口径

## 一、定位

BI 查询面板的**唯一计算机制**。模板全部为原始模板（不做任何命名解析、不做自动合并）；一切汇总、差值、比率、派生行，均在面板右下角 ⚡「模板公式」弹窗中显式配置，实时计算。

计算结果称为**合并行**（计算行），其引用的模板称为**参与项**。合并行置于面板顶部，多个依次置顶；参与项可展开折叠，紧随对应合并行。**参与项不再独立呈现**（收归子行，展开可见）；合并行出错（引用不存在/参与行查询失败）时其参与项保留独立行，保证数据可见。

## 二、语法

弹窗多行文本，每行一条：

```
# 注释行
结果名=表达式
净销售=总销售-退款
华东净增=华东_数量+华东_金额
结构占比=华东金额/总金额
```

- 运算符 `+` `-` `*` `/`（全角 `＝＋－×÷＊／` 自动归一），**标准优先级：先乘除后加减**；不支持括号，按优先级两遍折叠；
- 引用名解析用**词典最长匹配**：引用名可与模板名含相同字符（如含 `-`）而不被切碎；
- **只引用原始模板**：不支持层层嵌套（合并行不能再参与计算），保存时校验拒绝并提示；
- 结果名不得与模板名重复、不得重复定义。

## 三、计算口径（铁律）

1. **值字段**：严格按公式计算（先乘除后加减）；
2. **率字段**（有分子分母定义的五个率：边际利润率/配送费率/人工费率/平台费率/p4毛利率）：**公式计算后自动加权**——分子、分母分别按同一公式折叠后相除（如 `净销售=总销售-退款` 的率 =（总销售利润−退款利润）÷（总销售不含税金额−退款不含税金额）），**严禁**对率值直接加减；无分子分母定义的其他率字段按百分点值运算（业务含义由使用者负责）；
3. 任一引用不存在 / 参与行查询失败 / 任一操作数空 / 除数为 0 → 该列空（不猜 0）；
4. 参与行任一 loading → 合并行 loading；
5. 格式沿用首个有格式的参与行，回退字段默认格式；
6. 查询层联动：配置公式后，全部模板自动补查率字段的分子分母（`buildBatchQueryPlans` 依赖注入），保证率列加权可算。

## 四、展示与边界

- 合并行 `key = 'merge:结果名'`、`displayType = 'merged'`，置于显示行**最顶部**，其余行依次顺移；表格 / 目标表 / Excel 导出 / AI 快照同序；
- **参与项不独立呈现**：被成功计算的公式引用的模板行只以子行形态出现（展开可见，导出/下载/AI 快照以 `includeChildren` 强制展开）；出错公式行的参与项保留独立行；
- **展开折叠**：合并行名为可点击按钮，参与项紧随其后；导出时参与行跟随对应合并行；
- **目标按公式派生**：合并行的目标值 = 对参与项目标做同一公式折叠（率目标按百分点口径，任一参与项无目标→该列空）；达成率自动计算；派生目标**不可编辑**、**不出现在目标模板下载中**；**上传目标仅匹配原始模板**（模板上传即原样，无任何合并解析）；
- **趋势下钻**：双击合并行单元格 → 对全部参与模板逐节点查询，每节点按公式现算（值列直接折叠；率列分子分母分别折叠后相除，走率模型四阶段装饰与预测）；
- 引用失配显式降级：合并行名上带错误提示（title），不静默消失；
- **口径导出**：「下载全部模板口径」包含合并行——总表「项目明细」列出每条公式的表达式（与弹窗逐字一致）、参与项与状态，每个合并行另有同名分表（表达式/参与项/状态/计算说明）；状态复用 `validateFormulaText`（单一校验事实源）；
- 公式改动**无需失效查询缓存**（缓存只存原始行，公式为展示层派生），保存后仅重渲染。

## 五、存储

- D1 集合 `yeji_formulas`，docId = pid（非法字符替换 `_`），doc：`{ version:1, module:'ultra', text:全文, updatedAt }`，一个 pid 一份；
- 打开面板查询时随目标一并预加载（`ensureBatchFormulasLoaded`）；弹窗保存即生效。

## 六、文件与加载顺序

- `gs/gz.js`（`YejiPlcxGsGuize`，纯规则：解析/分词/优先级折叠/**单一计算核心** `computeFormulaValues`——显示行与趋势节点共用）；
- `gs/yw.js`（`YejiPlcxGsYewu`：存储/弹窗/合并行构建/率依赖解析/趋势节点求值）；
- `script.js` 清单位于 `plcx/hb/yw.js` 之后；`app.js` mixin 展开 + `checkBiModuleReady` 白名单均已登记。
