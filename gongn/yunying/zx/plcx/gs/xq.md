# 模板公式（gs/）需求与口径

## 一、定位

BI 查询面板的**显式派生行**机制，与「模板合并」（hb/，命名约定自动成组）互补：

- 合并：自动、无序、N 元（加法聚合），靠模板名前缀约定；
- 公式：显式、有序、人工定义（`+` `-` `×` `÷` 逐列运算），在面板右下角 ⚡ 弹窗维护。

公式结果 = **虚拟模板行**（不发起任何 BI 请求，纯前端对已查询的总计行做逐列算术）。

## 二、语法

弹窗多行文本，每行一条：

```
# 注释行
结果名=表达式
净销售=总销售-退款
华东净增=华东-华南          ← 可直接引用合并组名
经营净额=净销售-其他渠道      ← 可引用上方公式结果（链式）
结构占比=华东金额/总金额      ← 支持 ×÷
```

- 运算符 `+` `-` `*` `/`（全角 `＝＋－×÷＊／` 自动归一），**标准优先级：先乘除后加减**；不支持括号，按优先级两遍折叠；
- 引用名解析用**词典最长匹配**：引用名可与模板名含相同字符（如含 `-`）而不被切碎；
- 结果名不得与模板名/合并组名重复，不得重复定义；
- 公式引用可出现在任意运算符两侧（含 `×÷`），内部按子树递归求值。

## 三、计算口径（铁律）

1. 每列独立计算：**先乘除后加减**两遍折叠，操作数取各参与行 `valuesByKey`；
2. **率字段加减按百分点**（A率−B率），**严禁**对分子/分母分别运算后再相除；率字段参与 `×` `÷` 时按数值运算（业务含义由使用者负责）；
3. 任一引用不存在 / 参与行查询失败 / 任一操作数空 / 除数为 0 → 该列空（不猜 0）；
4. 参与行任一 loading → 虚拟行 loading；
5. 空值不参与、不补零；格式沿用首个有格式的参与行，回退字段默认格式；
6. 虚拟行结构 `formulaTree`：叶子项 `{op,name,key,keys}`（key=显示行 rowKey 供目标派生，keys=成员 key 供趋势聚合），组项同叶子结构（key=`merge:base`），公式引用项 `{op,name,children}` 递归子树。

## 四、展示与边界

- 虚拟行 `key = 'gs:结果名'`、`displayType = 'formula'`，由 `buildBatchFormulaRows` **置于显示行顶部**（其余行依次顺移）→ 表格渲染 / Excel 导出 / AI 快照**自动包含**且同序；
- **Excel 导出**（`includeFormulaChildren`）：虚拟行的参与行紧跟对应虚拟行之后，合并行维持既有收起行为（不展开子项）；
- **目标按公式派生**：目标表中虚拟行的目标值 = 对参与行目标做同样公式折叠（率目标按百分点口径，任一参与项无目标→该列空）；达成率 = 虚拟行实际值 ÷ 派生目标，自动计算；派生目标**不可编辑**（双击无效）、**不出现在目标模板下载中**（防止上传时对虚拟行设目标被静默丢弃）；AI 快照同步展示派生目标；
- **参与行可展开折叠**：与合并行同一机制（同一展开状态域 `batchGroupOpen`、同一 `data-group-key` 绑定）。虚拟行子项 = 公式直接引用的参与行（模板行缩进展示；合并组/公式行保留自身折叠按钮，可递归展开）；目标模板下载中不含公式行及其子项；
- **趋势下钻已支持**：双击虚拟行任意数值/达成率单元格 → 对公式树全部叶子模板逐节点查询（复用合并模板的并发查询），每个日期节点按公式树现算（叶子直接取值、合并组 aggregateField、公式引用递归），再走值模型四阶段装饰与预测；
- 公式行趋势**固定值模型**：率字段按百分点差展示，不提供 lfx 的分子/分母贡献度诊断（差值无分子分母，该诊断对其无数学意义）；
- 引用失配显式降级：虚拟行名上带错误提示（title），不静默消失；
- 公式改动**无需失效查询缓存**（缓存只存原始行，公式为展示层派生），保存后仅重渲染。

## 五、存储

- D1 集合 `yeji_formulas`（worker `ALLOWED` 白名单已加），docId = pid（非法字符替换 `_`，同 yeji_targets 规则）；
- doc：`{ version:1, module:'ultra', text:全文, updatedAt }`，一个 pid 一份；
- 打开面板查询时随目标一并预加载（`ensureBatchFormulasLoaded`）；弹窗保存即生效。

## 六、文件与加载顺序

- `gs/gz.js`（`YejiPlcxGsGuize`，纯规则：解析/分词/优先级折叠/节点求值）→ `gs/yw.js`（`YejiPlcxGsYewu`，存储/弹窗/虚拟行/趋势节点求值，UI 与服务链共用）；
- `script.js` 清单位于 `plcx/hb/yw.js` 之后、`qs/*` 之前；`app.js` mixin 展开 + `checkBiModuleReady` 白名单均已登记。
