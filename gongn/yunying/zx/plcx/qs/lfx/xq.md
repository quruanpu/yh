# 指标详解率模型

目标：服务不能直接累加的率字段，只做第一阶段解释模型，不做行业节奏预测。重点解释方向、依赖字段、业务基数字段、目标差、贡献拆解和基数可靠性。

适用字段：
- 不含税边际利润率
- 不含税配送费率
- 不含税人工费率
- 不含税平台费率
- 不含税P4毛利率
- 后续新增且能明确依赖字段和业务基数字段的率字段

请求策略：
- 继承当前 BI 汇总查询弹窗的模板、筛选、排除、快捷搜索、日期字段和目标。
- 查询字段只使用当前主日期字段。
- 聚合字段只请求当前率字段所需的依赖字段和业务基数字段。
- 合并模板先分别合并子模板依赖字段、业务基数字段，再计算率。

依赖规则：
- 不含税边际利润率 = 不含税边际利润 / 不含税金额
- 不含税配送费率 = 不含税配送费 / 不含税金额
- 不含税人工费率 = 不含税仓库人工费 / 不含税金额
- 不含税平台费率 = 不含税平台费 / 不含税金额
- 不含税P4毛利率 = 不含税p4毛利额 / 不含税金额

表格列：
- 星期
- 日期
- 时间进度
- 方向
- 率名称目标
- 当日依赖字段
- 累计依赖字段
- 当日业务基数字段
- 累计业务基数字段
- 当日率名称
- 日目标差
- 累计率名称
- 累计目标差
- 方向修正差
- 达标判断
- 率变化
- 依赖字段贡献
- 业务基数贡献
- 主导因素
- 基数可靠性
- 关键原因
- 建议动作

核心公式：
- 当日率 = 当日依赖字段 / 当日业务基数字段
- 累计率 = 累计依赖字段 / 累计业务基数字段
- 日目标差 = 当日率 - 目标率
- 累计目标差 = 累计率 - 目标率
- 方向修正差：利润率为累计率 - 目标率，费用率为目标率 - 累计率。方向修正差大于0统一表示好，小于0统一表示差。
- 率变化 = 当前累计率 - 上一节点累计率
- 依赖字段贡献 = 0.5 * ((当前依赖字段 - 上一节点依赖字段) / 上一节点业务基数 + (当前依赖字段 - 上一节点依赖字段) / 当前业务基数)
- 业务基数贡献 = 0.5 * (上一节点依赖字段 + 当前依赖字段) * (1 / 当前业务基数 - 1 / 上一节点业务基数)
- 主导因素根据依赖字段贡献和业务基数贡献绝对值判断，包括具体依赖字段主导、具体业务基数字段主导、共同影响、变化不明显和基数不足。
- 基数可靠性根据累计业务基数规模、当前进度和本轮最大业务基数占比判断，业务基数过小时不强解释率波动。

业务规则：
- 利润率类指标越高越好，例如不含税边际利润率、不含税P4毛利率。
- 费用率类指标越低越好，例如不含税配送费率、不含税人工费率、不含税平台费率。
- 边际利润率下降优先看利润额是否下降，以及不含税金额放大时利润是否同步增长。
- P4毛利率下降优先看商品结构、价格让利、促销和低毛利品类占比。
- 配送费率、人工费率、平台费率上升优先看费用绝对值是否增长快于不含税金额，以及销售规模是否未能摊薄费用。

边界：
- 不对率字段做每日率平均。
- 不对率字段做行业节奏预测。
- 不在业务基数不足时给确定性结论。
- 不把费用率偏高误判为正向信号，所有达标判断必须经过方向修正。
- 前端展示和AI回复不使用笼统术语，必须使用边际利润、不含税金额、配送费、人工费、平台费等具体业务字段名称。
