# 指标详解算法模块

目标：独立管理趋势面板算法，让查询、目标、模板、渲染与行业节奏判断解耦。

第一阶段只做解释型算法，不改变 BI 查询参数与结果口径。

输入：
- 趋势行：日期节点、星期、目标、当日数据、累计数据、达成率、查询时间进度、进度差、累计节奏、当日速度、速度变化。
- 趋势上下文：模板、字段、日期类型、目标区间等只读信息。

输出：
- 周内角色：周促峰值、周一后回落、连锁小高峰、连锁延续、延续回落、拼团观察、周低谷。
- 月内阶段：月初强促完整周、月初强促非完整周、月初效应延后、自然回落期、修复观察期、后段回落期、月底尾段。
- 节奏评级：强势领先、正常领先、基本同步、轻微落后、明显落后、高风险。
- 风险提示：基于周内角色、进度差、当日速度、速度变化生成短句。
- 趋势摘要：综合判断、风险提示、观察建议。

连续性规则：
- 连续高速天数：最近连续多少个节点当日速度 >= 1.1。
- 连续低速天数：最近连续多少个节点当日速度 < 0.9。
- 进度差趋势：最近节点进度差是收窄、扩大、稳定，区分落后与领先状态。
- 关键星期表现：星期一峰值、星期三小高峰、星期四延续的最近表现。

后续扩展：
- 行业预期进度。
- 行业进度差。
- 节假日修正。
- 平台/集团活动日修正。
- 3日平滑速度与平滑速度变化。
