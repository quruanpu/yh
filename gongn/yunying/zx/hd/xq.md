# 弹窗交互增强模块

目标：为 BI 查询、指标详解等运营弹窗提供统一的用户查看交互能力，不参与 BI 查询、节奏算法、目标配置和 AI 分析业务。

当前能力：
- 复制表格为图片：动态加载 html2canvas，只克隆当前弹窗内的主数据表格，完整展开所有行列后复制 PNG 到剪贴板。
- 全屏查看：给当前弹窗 dialog 添加统一全屏类，保持右上角关闭、复制图片、全屏按钮可用。

文件结构：
- `app.js`：按钮渲染和事件绑定入口。
- `fs.js`：放大缩小控制，只处理全屏状态和按钮图标。
- `tp.js`：图片复制控制，只处理主表格克隆、完整字段展开和剪贴板写入。

边界：
- 业务模块只负责在右上角渲染按钮，并在弹窗渲染后调用绑定方法。
- 本模块不读取或修改查询参数，不改变表格数据，不参与指标详解模型。
- 截图时只保留当前弹窗内的主数据表格，不复制标题、按钮、AI 面板、目标选择和状态栏，避免弹窗布局干扰图片结果。
- 截图副本会解除固定列和必要的省略限制，保证字段顺序、合并模板行名称和表格数据完整呈现。
- 全屏状态只由用户点击全屏按钮改变，数据刷新、AI 展开收起、后台校验更新都不能主动改变全屏状态。
- 浏览器不支持 ClipboardItem 或剪贴板权限不足时，只提示失败，不降级写入其它业务状态。

扩展：
- 后续如需下载图片、打印、复制表格，可继续在本目录新增能力，避免污染查询和分析模块。
