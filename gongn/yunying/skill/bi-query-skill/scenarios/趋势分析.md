# 趋势分析

## 触发意图

用户询问按日走势、累计走势、节奏、趋势、预测、为什么变化、月底能否达成、剩余日均压力时使用。

## 优先工具

指标详解。

## 常用参数

- `templateName` 或 `templateKey`
- `metricField`
- `startDate`
- `endDate`
- `targetKey` 或 `autoTarget:true`
- `dateField`

## 参数构造规则

- 用户指定模板和指标时，直接传入指标详解工具。
- 用户只问某模板“趋势怎么样”，但未指定指标时，需要根据当前面板指标或要求用户明确指标。
- 用户问本月和上月节奏对比时，使用 `queries` 传两个日期范围。
- 率指标必须依赖工具返回的 `rateDependency` 解释。

## 禁止事项

- 不要用主查询明细自行拼趋势。
- 不要自行预测月底结果，除非工具返回预测数据。
