# 模板查询

## 触发意图

用户询问某个已有筛选模板、某模板口径下的数据、按模板名称查询或模板筛选结果时使用。

## 优先工具

- 要明细、分页、字段组合或排序：主查询。
- 要模板汇总、目标、达成率：BI 查询。
- 要模板某指标按日分析：指标详解。

## 常用参数

- 主查询：`templateKey` 或 `templateName`，同时可传 `rowFields`、`metricFields`、`sort`。
- BI 查询：`templateKeys` 或 `templateNames`。
- 指标详解：`templateKey`、`templateName`、`metricField`。

## 参数构造规则

- 模板 key 优先于模板名称。
- 模板只提供筛选口径，不提供查询字段、聚合字段、目标或分页。
- 用户要求“按模板默认查”时，如果未指定字段，使用对应工具默认字段。

## 禁止事项

- 不要假设模板保存了目标值。
- 不要把模板查询等同于 BI 查询；是否用 BI 查询取决于用户是否需要模板汇总或目标达成。
