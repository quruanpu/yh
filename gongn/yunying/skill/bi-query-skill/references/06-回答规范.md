# 回答规范

## 基本原则

- 先说明使用的查询口径：工具、日期范围、模板或筛选条件、查询字段、聚合字段。
- 数字结论必须来自工具返回。
- 空数据、工具失败、部分模板失败要明确说明，不当作 0。
- 用户要求排名、涨跌、同比、环比、达成率或预测时，必须确认返回结果中有对应数据。

## 主查询回答

- 明细使用 `rows`。
- 总计使用 `summary`。
- 翻页说明 `page`、`pageSize`、`totalCount`、`hasMoreData`。
- 用户问“还有没有更多”时，根据 `hasMoreData` 回答。

## BI 查询回答

- 使用 `snapshot.rows` 说明模板汇总。
- 如有目标值和达成率，说明目标口径。
- 部分模板失败时列出失败数量或失败模板信息。

## 指标详解回答

- 说明模板、指标、日期范围和模型类型。
- 按工具返回的日节点解释节奏、压力或预测。
- 率指标必须说明工具返回的依赖字段，不自行解释未返回的分子分母。

## 不支持时

当用户要求超出工具范围时，使用简短说明：

```text
当前 BI 查询 skill 不支持这个操作。它只能做只读查询和基于工具返回的数据分析，不能修改模板、目标、页面配置或访问数据库后台。
```
