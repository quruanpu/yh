# 工具协议

本文件描述当前 BI 查询 skill 可调用的三个只读工具。参数必须符合工具 schema，不要传入未声明字段。

## 主查询工具

工具名：`yeji_main_query_page`

用途：执行 BI 主查询页面业务壳，返回分页明细和总计行。

支持参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `page` | number | 页码，默认 1 |
| `pageSize` | number | 每页数量，最大 100 |
| `inheritCurrent` | boolean | 是否继承当前页面筛选、字段和快捷搜索，默认 false |
| `filters` | object | 筛选条件，键为筛选字段名称或 cdId |
| `excludeMode` | object | 排除模式，键为筛选字段名称或 cdId，值为 true |
| `rowFields` | string[] | 查询字段名称或 key |
| `metricFields` | string[] | 聚合字段名称或 key |
| `templateKey` | string | 模板 key，优先于模板名称 |
| `templateName` | string | 模板名称 |
| `sort` | object | `{ "field": "字段名或key", "order": "asc|desc" }` |
| `queries` | object[] | 多组查询，最多 31 组 |

返回核心字段：`success`、`page`、`pageSize`、`sort`、`template`、`totalCount`、`hasMoreData`、`summary`、`rows`。

最小可调用参数：无。无参数时走主查询默认口径。

默认/继承行为：

- 默认不继承当前页面，使用主查询默认口径。
- 需要当前页面筛选、字段或快捷搜索效果时，传 `inheritCurrent:true`。
- 工具没有独立快捷搜索参数；快捷搜索只能通过继承当前页面状态获得。

必须追问条件：

- 用户要求不存在的筛选字段、查询字段或聚合字段。
- 用户要求按只能展示的字段筛选，但系统没有对应筛选项或 cdId。

## BI 查询面板工具

工具名：`yeji_batch_query_panel`

用途：执行 BI 查询面板业务壳，返回模板维度汇总、目标值和达成率。AI 只传参数，计算由面板完成。

支持参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `startDate` | string | 开始日期，格式 `YYYY-MM-DD` |
| `endDate` | string | 结束日期，格式 `YYYY-MM-DD` |
| `templateKeys` | string[] | 模板 key 列表 |
| `templateNames` | string[] | 模板名称列表 |
| `filters` | object | 筛选条件，键为筛选字段名称或 cdId |
| `excludeMode` | object | 排除模式，键为筛选字段名称或 cdId，值为 true |
| `dateField` | string | 日期字段，支持出库日期或支付日期 |
| `metricFields` | string[] | 聚合字段名称或 key |
| `targetKey` | string | 目标范围 key |
| `autoTarget` | boolean | 是否自动匹配目标，默认 true |
| `includeChildren` | boolean | 合并模板是否返回子项，默认 true |
| `queries` | object[] | 多组查询，最多 31 组 |

返回核心字段：`success`、`queryTime`、`rowStatus`、`lockedContext`、`snapshot`。

最小可调用参数：无。无参数时查询当前 BI 查询面板模板列表，并继承当前页面日期筛选。

默认/继承行为：

- 默认继承当前页面筛选日期。
- 传入 `startDate/endDate` 时，会用 `dateField` 指定的日期字段覆盖日期范围；未传 `dateField` 时默认使用系统默认日期字段。
- 未传模板时查询当前 BI 查询面板全部模板。
- 未传 `targetKey` 且 `autoTarget` 不为 false 时，系统按日期自动匹配目标。
- 用户只给模板名称时，传 `templateNames`；知道模板 key 时，优先传 `templateKeys`。

必须追问条件：

- 用户指定模板但名称或 key 无法匹配。
- 用户指定目标范围但没有可用 `targetKey` 或目标范围无法匹配。
- 用户问题必须依赖目标达成率，但工具返回中没有目标或达成率。

## 指标详解工具

工具名：`yeji_trend_query_panel`

用途：执行指标详解面板业务壳，返回某模板或合并模板的某指标按日节点分析。AI 只传参数，计算由面板完成。

支持参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `startDate` | string | 开始日期，格式 `YYYY-MM-DD` |
| `endDate` | string | 结束日期，格式 `YYYY-MM-DD` |
| `templateKey` | string | 单个模板 key |
| `templateName` | string | 单个模板名称 |
| `templateKeys` | string[] | 多个模板 key |
| `templateNames` | string[] | 多个模板名称 |
| `filters` | object | 筛选条件，键为筛选字段名称或 cdId |
| `excludeMode` | object | 排除模式，键为筛选字段名称或 cdId，值为 true |
| `dateField` | string | 日期字段，支持出库日期或支付日期 |
| `metricField` | string | 指标字段名称或 key |
| `targetKey` | string | 目标范围 key |
| `autoTarget` | boolean | 是否自动匹配目标，默认 true |
| `queries` | object[] | 多组查询，最多 31 组 |

返回核心字段：`success`、`queryTime`、`lockedContext`、`snapshot`。

最小可调用参数：如果当前指标详解面板已打开，可不传模板、指标、日期或目标，工具会优先沿用当前上下文；没有当前上下文时，至少需要能确定指标字段，并能通过模板/日期匹配目标。

默认/继承行为：

- 当前指标详解面板已打开且未传模板时，沿用当前模板或合并模板。
- 当前指标详解面板已打开且未传指标时，沿用当前指标。
- 当前指标详解面板已打开且未传目标时，沿用当前目标；否则按日期自动匹配目标。
- 传入 `startDate/endDate` 时覆盖日期范围；未传时优先沿用当前面板日期或当前页面日期筛选。
- 用户只给模板名称时，传 `templateName` 或 `templateNames`；知道模板 key 时，优先传 key。

必须追问条件：

- 没有当前指标详解上下文，且用户没有指定指标字段。
- 用户要求趋势分析但没有模板或可匹配模板。
- 指标没有目标，或率字段缺少工具返回的依赖字段。

## `queries` 规则

- 三个工具都支持 `queries`，最多 31 组。
- 每个 `queries` 子项是一组完整查询参数。
- 为避免歧义，推荐把每组查询需要的日期、模板、筛选、字段和目标都写入子项。
- 不要假设子项会自动继承顶层参数；如果要复用同一模板或字段，在每个子项里重复写明。
- 多组查询返回 `queryCount` 和 `results`，每个 `results` 元素按单组查询返回结构理解。
