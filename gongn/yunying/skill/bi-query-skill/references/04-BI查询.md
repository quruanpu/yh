# BI 查询

BI 查询用于模板维度汇总、模板对比、目标值、达成率和合并模板结果。工具名为 `yeji_batch_query_panel`。

## 适用问题

- 查询所有模板或指定模板的汇总表现。
- 对比多个模板的含税金额、利润、费用率、客户数等聚合指标。
- 查看目标值、达成率、目标差额或完成进度。
- 使用同一口径对比多个日期区间。

## 参数要点

- `templateKeys` 或 `templateNames` 指定模板；未传时默认查询当前 BI 查询面板全部模板。
- `dateField` 只支持出库日期或支付日期。
- `startDate` 和 `endDate` 指定日期范围；未传时继承当前页面日期筛选。
- `metricFields` 指定聚合字段；未传时使用 BI 查询面板默认聚合字段。
- `targetKey` 指定目标范围；未传且 `autoTarget` 不为 false 时，系统按日期自动匹配目标。
- `includeChildren` 控制合并模板是否返回子项，默认 true。

## 选择优先级

- 模板 key 优先于模板名称；用户只给名称时传 `templateNames`。
- 目标 key 优先于自动匹配；用户没有明确目标范围时保持 `autoTarget:true`。
- 用户问“当前 BI 查询面板”时可以不传模板，让工具使用当前模板列表。
- 用户指定日期时必须同时传 `startDate` 和 `endDate`。

## 自定义筛选

`filters` 可传当前字段字典支持的筛选字段。BI 查询会在模板口径基础上叠加这些筛选条件，并由面板重新计算。

## 多组对比

需要本月与上月、多个日期范围或多个目标范围对比时，使用 `queries`：

```json
{
  "queries": [
    { "startDate": "2026-06-01", "endDate": "2026-06-15" },
    { "startDate": "2026-05-01", "endDate": "2026-05-15" }
  ]
}
```

## 返回理解

- `snapshot.rows` 是模板维度汇总行，不是订单明细。
- 行内可能包含目标值、达成率和面板计算字段。
- `rowStatus.total` 是模板行数，`rowStatus.success` 是成功行数，`rowStatus.failed` 是失败行数。
- `success:false` 表示全部模板失败；部分失败时必须在回答中说明。

## 禁止事项

- 不要自行计算目标值、达成率或合并模板。
- 不要把 `snapshot.rows` 当作主查询明细。
- 不要在工具未返回目标字段时声称已经达成或未达成。
