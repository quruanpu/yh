# 主查询

主查询用于分页明细、总计行、字段组合、自定义筛选、模板筛选、快捷搜索、排序和翻页。工具名为 `yeji_main_query_page`。

## 适用问题

- 查询当前页或某一页明细。
- 查询客户、商品、区域、活动、订单等明细和汇总。
- 自定义任意支持的筛选字段、查询字段和聚合字段。
- 批量筛选多个普通字段，并指定排序。
- 使用已有筛选模板查询。

## 默认查询

不传参数时，主查询使用系统默认口径：

- 筛选：出库日期为本月第一天到昨天。
- 查询字段：出库月份（月）、省份、客户名称、客户类型。
- 聚合字段：含税金额、不含税边际利润、不含税边际利润率、不含税人工费率、不含税配送费率。

默认查询不继承当前页面状态。需要沿用当前页面筛选、字段、模板或快捷搜索时，显式传 `inheritCurrent:true`。

## 自定义筛选

`filters` 支持多个字段同时传入：

```json
{
  "filters": {
    "客户名称": ["客户A", "客户B"],
    "商品名称": { "manual": "商品A\n商品B" },
    "省份": "重庆",
    "出库日期": { "range": ["2026-06-01", "2026-06-15"] }
  }
}
```

日期字段使用 `{ "range": ["开始日期", "结束日期"] }`。普通字段可传字符串、数组、`manual` 或 `selected`。区域树可传 `treePaths`。

## 字段配置

- `rowFields` 控制查询字段。
- `metricFields` 控制聚合字段。
- 如果用户要求“按客户看商品”，应把客户和商品字段都放入 `rowFields`。
- 如果用户要求“只要汇总”，仍可通过主查询读取 `summary`，不要把 `rows` 当汇总。

## 模板查询

使用 `templateKey` 或 `templateName`。`templateKey` 优先。模板提供筛选口径，不保存查询字段、聚合字段、目标或分页；字段仍由 `rowFields` 和 `metricFields` 控制。

## 排序与分页

排序格式：

```json
{
  "sort": {
    "field": "含税金额",
    "order": "desc"
  },
  "page": 1,
  "pageSize": 20
}
```

`order` 只允许 `asc` 或 `desc`。翻页时传入新的 `page`。每页数量最大 100。

## 多组查询

需要对比多个时间段或多个口径时，优先使用 `queries`，单次最多 31 组。

## 返回理解

- `rows` 是当前分页明细。
- `summary` 是总计行。
- `totalCount` 是命中总条数。
- `hasMoreData` 表示是否还有下一页。
- 主查询不返回目标达成率；需要达成率时使用 BI 查询面板。
