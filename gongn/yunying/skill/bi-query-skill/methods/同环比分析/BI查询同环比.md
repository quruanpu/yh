# BI 查询同环比

BI 查询同环比用于当前 BI 查询面板或模板维度的时间对比。工具名为 `yeji_batch_query_panel`。

## 默认上下文

当前 BI 查询面板打开时，优先沿用当前面板的模板列表、日期筛选、目标匹配、聚合字段和合并模板设置。用户只说“当前这些模板”“这个面板”“这些项目同环比”时，不要切到主查询。

## 适用问题

- 模板本期、同期、环期表现对比。
- 多模板排名、增量、掉量、达成率变化。
- 合并模板及其子模板贡献变化。
- 目标值、达成率、目标差额在不同时间区间的变化。

## 查询策略

- 未指定模板时，不传 `templateKeys/templateNames`，让工具查询当前 BI 查询面板模板列表。
- 用户指定模板时，模板 key 优先；没有 key 时传 `templateNames`。
- 日期对比使用 `queries`，本期、同期、环期放在同一次工具调用中。
- 需要目标达成时保持 `autoTarget:true`；用户指定目标范围时传 `targetKey`。
- 合并模板需要拆子项时保持 `includeChildren:true`。

## 复核与计算

- `snapshot.rows` 是模板维度汇总行，不是客户或商品明细。
- 行内有目标值、达成率、目标差额时，优先使用工具返回值，不自行重算目标。
- 模板对齐优先使用模板 key，其次模板名称。
- 部分模板失败时，必须说明失败模板，不把失败模板按 0 计入排名。
- 如需解释某个模板掉量原因，可再用主查询或指标详解补查，但补查结果只能作为原因证据，不能和 BI 查询 rows 跨口径混算。

## 输出

说明当前 BI 查询面板口径、模板范围、日期字段、本期、同期、环期、目标口径和是否包含子模板。再输出整体变化、模板增量/掉量、目标达成变化和需要关注的模板。
