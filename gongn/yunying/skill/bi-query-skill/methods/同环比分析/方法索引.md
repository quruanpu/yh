# 同环比分析方法索引

同环比是一种时间对比方法，不是固定工具。先识别用户要比较的主体、指标、维度和时间，再根据当前打开面板选择取数路径。

## 默认路由

- 当前打开指标详解弹窗时，读取 `methods/同环比分析/指标详解同环比.md`，默认使用 `yeji_trend_query_panel`。
- 当前打开 BI 查询面板时，读取 `methods/同环比分析/BI查询同环比.md`，默认使用 `yeji_batch_query_panel`。
- 没有业务弹窗，或用户明确问客户、商品、品种、明细、贡献客户、采购结构时，读取 `methods/同环比分析/主查询同环比.md`，默认使用 `yeji_main_query_page`。

## 灵活切换

当前面板只是默认口径，不是唯一工具。若用户明确指定其它工具或当前工具无法取得必要证据，可以使用其它工具辅助，但必须说明各工具口径，不能跨工具混算。

## 时间口径

日期字段默认 `出库日期`；用户明确支付口径时用 `支付日期`。

本期优先使用用户指定日期。用户未指定日期时，使用系统默认当前期。同期默认取本期向前平移一年；环期默认取与本期等长且紧邻本期开始日前一天结束的区间。用户明确“上月同期”时，按自然月同日区间处理。

所有工具入参都必须是明确的 `YYYY-MM-DD`，且开始日期不晚于结束日期。

## 计算规则

- 变化额 = 本期值 - 对比期值。
- 变化率 = 变化额 / 对比期值；对比期为 0 或缺失时不输出变化率。
- 增量按变化额降序，掉量按变化额升序。
- 贡献最大按对应区间指标值降序。

空值、横杠、非数字文本不能当 0，除非工具明确返回数值 0。工具失败、空数据或未查询到不能当成 0。

## 输出

先说明查询口径：当前上下文、使用工具、主体、日期字段、本期、同期、环期、核心指标和分页范围。再给结论、变化证据和经营观察。不要输出 Markdown 表格。
