# 指标详解同环比

指标详解同环比用于当前指标详解弹窗中的时间对比、趋势节奏、目标压力和预测诊断。工具名为 `yeji_trend_query_panel`。

## 默认上下文

当前指标详解弹窗打开时，优先沿用弹窗里的模板、指标、日期、目标、模型类型和值/率依赖。用户只说“这个指标同环比”“当前趋势和上月比”“为什么变了”时，不要切到主查询。

## 适用问题

- 当前指标本期、同期、环期的按日节点对比。
- 累计走势、日均节奏、目标压力、月底预测变化。
- 值模型指标的金额、数量、客户数变化。
- 率模型指标的率值变化及工具返回的分子分母依赖变化。

## 查询策略

- 当前弹窗已打开且用户未指定模板、指标或目标时，不传这些参数，让工具沿用当前上下文。
- 用户指定日期时，传 `startDate/endDate`；未指定时沿用当前面板日期。
- 本期、同期、环期用 `queries` 并发查询。
- 用户要求解释客户、商品、品种原因时，先用指标详解判断时间节点和指标变化，再用主查询补充明细原因。

## 复核与计算

- `snapshot.rows` 是指标详解面板算法后的按日节点，不是原始明细。
- `lockedContext` 是口径边界，回答中必须以其模板、指标、日期和目标为准。
- 率模型必须使用工具返回的 `rateDependency` 解释，不自行选择分子、分母或业务基数。
- 工具未返回预测或达成率时，不自行预测或计算。
- 不同模板、目标范围或日期字段不能混算。

## 输出

说明当前指标详解口径、指标模型、日期字段、本期、同期、环期和目标口径。再输出累计变化、节奏变化、关键日期节点、目标压力或预测变化。需要原因拆解时，说明是否已使用主查询补充证据。
