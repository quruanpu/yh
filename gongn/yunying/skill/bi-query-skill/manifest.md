# Skill 清单

先根据用户意图匹配场景或方法，再读取对应文档。新增业务场景时放入 `scenarios`；新增通用分析方法时放入 `methods`。不要把具体业务分析流程写进通用运行时规则，除非底层工具协议发生变化。
